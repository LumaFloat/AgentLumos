# Contributing

Thanks for your interest in AgentLumos.

## Workflow

1. Fork or branch from the public repository.
2. Install dependencies with `npm install`.
3. Run `npm test` and `npm run build` before submitting changes.
4. Keep changes focused and avoid committing private internal notes or planning documents.

## Local Checks

```powershell
npm test
npm run build
```

## Scope

Public contributions should stay within the open-source tree:

- `src/`
- `tests/`
- `README.md`
- `README.zh-CN.md`
- `docs/hooks/`
- `docs/manual-windows-test.md`
- `package.json`
- `package-lock.json`
- `tsconfig.json`
- `vitest.config.ts`

Private planning documents from internal worktrees are not part of the public contribution workflow.
